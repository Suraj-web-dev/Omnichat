1. Executive Summary & Tech Stack

OmniChat is an advanced, high-performance conversational AI platform designed to overcome the single-model limitation of conventional AI chat applications like ChatGPT. Rather than locking the user into a single LLM perspective, OmniChat dispatches prompts concurrently across 3 frontier AI models on 100% free API tiers, calculates latency and token throughput in real time, and features a proprietary Master Synthesis Engine to combine unanimous consensus, superior code snippets, and critical edge cases into one authoritative answer.

2. Complete End-to-End Data & Code Flow

The lifecycle of every user prompt traces through a decoupled, asynchronous path designed for fault tolerance and sub-second feedback:

1

User Interaction in ChatInput.jsx

User enters inquiry. Keyboard listeners detect Enter (submit) vs Shift+Enter (newline). Triggers sendMessage(prompt) in useChat.js.

2

Optimistic Client State & Loading Skeleton

A unique UUID is generated. Placeholder model cards with animated skeleton loaders immediately render on screen in MultiModelResponse.jsx so UI never feels stalled.

3

HTTP POST Dispatch to Express Backend

src/services/api.js calls POST /api/conversations/:id/messages. messageRoutes.js passes execution to messageController.js.

4

Parallel Multi-Model Dispatch with 9s Safeguard

server/services/aiService.js calls Promise.allSettled([Groq, Cohere, Gemini]) wrapped inside withTimeout(..., 9000). Fast models resolve in 300-800ms; slow models cleanly fall back without blocking.

5

MongoDB Persistence & Client Render

Responses, latency metrics, and token counts are saved in MongoDB. The frontend replaces loading cards with live model content, syntax-highlighted code, and ⚡ Latency HUD.

6

Selection or AI Master Consensus (Unique Feature)

Option A: User clicks "Choose this Answer" to lock in an individual model.
Option B: User clicks "✨ Synthesize Master Answer". Backend runs meta-prompting to combine unanimous consensus, optimal code patterns, and security caveats into one unified response.

6. Production Resilience & Stability Guardrails

  • Non-Blocking 9-Second Timeouts: Each model in aiService.js is wrapped with withTimeout(). If one provider experiences cloud latency, other models still return in milliseconds.
  • Groq OTPM Optimization: Groq free tier imposes a strict 1000 output tokens per minute ceiling. max_tokens is clamped at 850, completely eliminating 429 rate_limit_exceeded errors.
  • Dual-Mode Storage Architecture: If MongoDB local service is inactive, the backend automatically falls back to an in-memory database and frontend local storage, guaranteeing 100% uptime for local development.
  • Fastest Gemini Production Endpoint: Configured to use gemini-flash-latest, resolving Google AI Studio 503 high-demand spikes.

7. REST API Endpoints Specification

Method Endpoint Path Description & Payload
GET /api/health Returns server status, MongoDB connection status, and status of configured AI API keys.
GET /api/conversations Fetches all conversation sessions sorted by updatedAt descending.
POST /api/conversations Creates a new conversation session. Body: { title: "Session Name" }.
PATCH /api/conversations/:id Renames a conversation. Body: { title: "New Title" }.
DELETE /api/conversations/:id Permanently removes a conversation and its messages.
POST /api/conversations/:id/messages Broadcasts prompt to Groq, Cohere, and Gemini in parallel. Body: { prompt: "..." }.
PATCH /api/conversations/:id/messages/:messageId/select Locks in chosen winner model ID. Body: { selectedModelId: "gpt-4o" }.
POST /api/conversations/:id/messages/:messageId/synthesize Synthesizes all 3 model answers into a Master Answer and sets it as the chosen winner.
