CHAPTER 1: INTRODUCTION

1.1 Project Overview

OmniChat (Snitch) is a conversational artificial intelligence platform engineered to eliminate single-model bias, hallucination, and lack of performance transparency. Rather than constraining users to a single LLM perspective, OmniChat broadcasts inquiries concurrently to three independent frontier AI models: Groq Cloud (Qwen 3.8 / LPU), Cohere AI (Command R), and Google AI Studio (Gemini Flash). The system provides real-time millisecond inference benchmarks and features a proprietary Master AI Synthesis Engine that combines the strongest attributes of all models into one unified response.

1.2 Background and Motivation

Different Large Language Models exhibit distinct trade-offs: Groq provides near-instantaneous code syntax on LPUs; Cohere excels in nuanced architectural prose; Google Gemini provides vast knowledge and safety guardrails. In traditional chatbots, accessing multiple perspectives requires manual tab switching and cognitive friction. OmniChat was motivated by the vision of a centralized Multi-AI Intelligence Workspace that automates parallel querying and multi-agent synthesis.

1.3 Problem Statement

  • Single-Model Hallucinations: Users lack an immediate cross-verification mechanism for algorithmic code and technical facts.
  • Opaque Hardware Performance: Standard interfaces hide backend latency, token velocities, and cost metrics.
  • Binary Decision Compromise: Comparing outputs traditionally forces users to discard 66% of generated insights.

1.4 Objectives & Scope

The primary objectives are: (1) Orchestrate concurrent multi-LLM execution via non-blocking asynchronous event loops; (2) Implement an automated Master Consensus Engine; (3) Expose live developer latency and token HUDs; (4) Provide 100% free-tier operation with 9-second fail-safe timeout protection.

5.2 Key Code Listings

1. Fail-Safe Timeout Wrapper (server/services/aiService.js):

function withTimeout(promise, ms, onTimeout) {
  let timer;
  const timeoutPromise = new Promise((resolve) => {
    timer = setTimeout(() => resolve(onTimeout()), ms);
  });
  return Promise.race([
    promise.then(res => { clearTimeout(timer); return res; }),
    timeoutPromise
  ]);
}
